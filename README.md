Um projeto de chatbot básico que contém scripts e exemplos para criar conversas simples em linha de comando ou com interface gráfica (se houver arquivos de interface no repositório).

Instale dependências (se existir requirements.txt):

```bash
pip install -r requirements.txt
```

## Como executar

Exemplo genérico (substitua pelo script principal do repositório):

```bash
python main.py
```

ou

```bash
python chatboot.py
```
